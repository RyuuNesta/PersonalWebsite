# Ryu Nesta Nuriadi Portfolio

A modern personal portfolio website built with semantic HTML, Tailwind CSS, and vanilla JavaScript. The site features a dark mode aesthetic with emerald accent colors, smooth scrolling navigation, responsive layout, and a working contact form.

## Project Structure

- `index.html` — Main portfolio page containing the hero, about, education, skills, projects, contact, and footer sections.
- `style.css` — Custom styles for gradients, animation, timeline markers, cards, and interactive UI details.
- `script.js` — JavaScript functionality for the mobile menu, contact form validation, smooth scrolling, and scroll-based section animations.

## Setup

1. Open `index.html` in your browser.
2. Optionally, run a local server for best results (for example using VS Code Live Server or `python -m http.server`).

## Customization

- Update the personal content directly in `index.html`.
- Modify colors and animations in `style.css`.
- Extend form behavior or add backend integration in `script.js`.

## Notes

- The website is fully mobile responsive using Tailwind utility classes and custom CSS.
- Navigation links include smooth scrolling to each section.
- The contact form simulates submission with validation and visual feedback.
